# Clawbound typography

Self-hosted fonts, bundled for offline play. No third-party font requests.

- Manrope 5.2.8: UI and numerals; Fontsource package @fontsource/manrope; weights 400,600,700,800, Latin WOFF2.
- Barlow Condensed 5.2.7: display titles and primary controls; Fontsource package @fontsource/barlow-condensed; weights 600,700, Latin WOFF2.

Both fonts are licensed under the SIL Open Font License 1.1. Complete licenses are included beside these files. The distributed files are unmodified Fontsource font binaries.
