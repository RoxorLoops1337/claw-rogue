# Claw Rogue

A self-contained browser claw-machine roguelike with colliding prizes, turn-based combat, room progression, and upgrades.

## Play

Use the on-screen left/right buttons or A/D or arrow keys to aim. Press Drop or Space to grab. The claw lifts and delivers the prize automatically. Weapons damage enemies; hearts heal; shields block attacks. Defeat an enemy to choose an upgrade.

## Run locally

Open index.html in a modern browser. No build step or dependencies.

## Development status

Early prototype. The pile uses circle collision physics; gripping uses proximity detection and a held-object animation.
